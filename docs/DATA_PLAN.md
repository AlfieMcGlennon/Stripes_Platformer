# Data Plan

Principle: the game ships **small, pre-processed, committed JSON** generated by one reproducible Python script (`scripts/build_data.py`). No runtime fetching, no API keys, no CORS. Every dataset gets a citation and licence in `data/SOURCES.md` and in the in-game credits.

> All figures below marked *verify* must be checked against the source at build time; do not quote them in-game until the script has produced them.

**Deviations from the plan above:**
- **ERA5 daily is not used yet.** The build environment's network policy blocked Copernicus/ECMWF, Met Office and NOAA hosts, so level 1 uses real *monthly* data instead of daily. Monthly global data is already noisy enough to make the point (month-to-month swings of up to ~0.35 °C in the window). Swapping in ERA5 daily anomalies later is a data-only change: add a fetch step, emit a daily series, point `MonthsScene` at it.
- **No paleo time series.** Tierney 2020 is two snapshots, so the slide draws the deglaciation as a straight line at its *average* rate over an assumed 10,000 years (20–10 ka), and the Holocene as flat. Both are stated in the credits. Osman et al. 2021 (LGMR) would give a real curve; swap it in when its data can be fetched.
- Sources/checksums are recorded in `data/sources.json` (not `SOURCES.md`).
- Stripe colours are centred on the 1971–2000 mean with a ±2.6σ (1901–2000) range, our reading of the showyourstripes convention (*verify* against Ed Hawkins' method). In-game numbers are vs 1850–1900.

## Processing pipeline (`scripts/build_data.py`)
1. **Fetch** raw files into `scripts/raw/` (gitignored), record URL + retrieval date + checksum in `data/SOURCES.md`.
2. **Clean:** handle missing values explicitly (no silent interpolation; log counts).
3. **Rebase:** express anomalies relative to **1850–1900** ("pre-industrial", common IPCC convention) so numbers match public messaging. Record the baseline in each JSON's metadata. For the stripes, colour scale is symmetric around a chosen reference and fixed across the whole game.
4. **Slice** windows the levels need:
   - `daily_global_<window>.json` — e.g. 1–3 years of ERA5 daily global anomalies for level 1 (choose a window that is representative, *not* cherry-picked; document the rule, e.g. "a random year from 1940–2000, seed fixed").
   - `monthly_global.json`, `annual_global.json` — HadCRUT5 monthly and annual for level 2 (plus ERA5 aggregates for the overlap check).
   - `global_annual.json` — 1850–latest complete year, with anomaly and uncertainty if available.
   - `paleo.json` — resampled onto a regular time grid, plus the recent instrumental segment joined and clearly flagged as a different source.
5. **Derive** headline numbers (total warming, rate per century, ratio paleo vs recent) and write to `derived.json`. The game displays only these computed values.
6. **Validate** (pytest): schema, monotonic time, no NaN, expected ranges, expected row counts, baseline metadata present.
7. **Emit** minified JSON into `src/data/`. Target total < 300 KB.

## Data-to-game mapping
- **Terrain height** = value × scale, where scale is a per-level constant so that daily swings look big and the annual staircase looks small at first, then dominant after the pull-back (the perceptual point of the game).
- **Zoom** = re-binning the same series (daily → monthly → annual) with the anchor x kept under the player. Precompute all resolutions so zoom is a pure tween.
- **Stripe colour** = diverging palette over the anomaly, fixed range across all years.

## Honesty checks (things a climate scientist will look for)
- Local daily series ≠ global signal. Say so when moving from level 2 (local weather) to level 3 (global mean). One line of text is enough.
- Paleo and instrumental records have different resolution and uncertainty; smoothing on the paleo side means "rate" comparisons need care. Show the sources' timescale caveat in credits and compute rates over comparable windows (e.g. per century averaged over the deglaciation vs the last 50 years).
- Always label baseline and units.
- Do not show a projection unless it is sourced (e.g. a named IPCC scenario) and labelled as such.
